# Retro radio design choice

The user selected **A · Valnød** after comparing three interactive radio
prototypes. The question was which retro radio composition should guide the
living-room tablet app. No further reason was stated.

Primary source: [prototype/retro-radio at f4faf50](https://github.com/stefan520/radioapp/tree/f4faf50),
including `src/radio.prototype.html` and its three URL variants. The alternatives
remain on that branch; the production page contains only the chosen direction.

The implementation uses the walnut enclosure, brand strip, left-hand fabric
speaker, green display and cream transport from A. Existing production features
remain, including album art, larger track text, the wider Aakirkeby weather
column, twelve stations, photo albums, swipe slideshow and screen wake lock.

On phones, the decorative speaker hides and playback/volume controls wrap.
The independent visual review found no material desktop/mobile regressions.
